# OpticsVerse 3D — Sandbox Physics Lab

An interactive 3D optics learning platform built with Three.js. Explore reflection, refraction, and advanced optics concepts through hands-on simulations and quizzes.

## 🔗 Live Demo

**[🚀 Launch OpticsVerse 3D](https://huggingface.co/spaces/Vishu54645/opticsverse-3d)**

## Features

- **Sandbox Mode** — Place light sources, mirrors, and lenses to trace rays in real-time
- **3D Rendering** — Interactive Three.js scenes with ray tracing visualization
- **Optics Tools** — Plane, concave, and convex mirrors & lenses
- **Study Mode** — Learn reflection, refraction, and advanced optics concepts
- **Quizzes** — Test your knowledge with interactive physics quizzes

## Tech Stack

- **Three.js** — 3D rendering and ray tracing
- **Vanilla JS** — Lightweight, zero-dependency frontend
- **HuggingFace Spaces** — Static hosting with auto-deploy from GitHub

## Deployment

Auto-deployed from GitHub via [huggingface/hub-sync](https://github.com/huggingface/hub-sync) GitHub Action. Push to `main` and the Space updates automatically.
